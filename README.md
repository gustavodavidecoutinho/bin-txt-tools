`BinTxtTools` 

## BinTxtTools is a lightweight utility available as both a Command Line Interface (CLI) tools and a native iOS Application built with SwiftUI. Designed for developers and tech enthusiasts to easily decode binary streams into plain text and encode text back into binary.

## Features 
Dual Platforms: Available as a Python CLI tool and a native SwiftUI iOS app.

Decode Binary: Convert raw binary streams into readable text strings instantly.

Encode to Binary: Transform plain text or ASCII strings into standard 8-bit binary formats.


Installation & Usage 🛠️

## 1. CLI Version (Terminal)

You can install the tool directly from GitHub using `pip`:

`pip3 install --user git+https://github.com/gustavodavidecoutinho/bin-txt-tools.git`


## 2. iOS Version via Sideloadly
If you want to install the native iOS app onto your physical iOS device using Sideloadly, follow these steps:

Prerequisites: A computer with `sideloady!`, and an Apple ID.

Steps:

Get or build the .ipa file from this github on /iOS_App/BinTxtTools.ipa (you can also download the full xcode project to modify something or install it yourself!).

Connect your iPhone via USB/Lightning and open Sideloadly.

Drag and drop the BinTxtTools.ipa file into Sideloadly.

Enter your Apple ID and click Start to sign and install the app locally.

Go to your iPhone's Settings > General > VPN & Device Management, trust your developer profile

The app will then be installed on you iPhone, if you try to open the app as it is is probably won't work as you need to go to Settings --> Privacy & Security --> Developer Mode --> ON

`Congrats!` You successfully installed BinTxtTools on your platform
