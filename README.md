# bin-txt-tools 

> The ultimate open-source CLI suite to decode binary, render pixel art matrices, and convert text or ASCII art into binary.

`bin-txt-tools` is a lightweight, robust command-line utility built in Python designed for developers, students, and enthusiasts who need to handle binary data, text encodings, and pixel matrix graphics directly from the terminal without any hassle.

---

##  Features

- **Binary to Text Decoder:** Easily convert raw binary strings into readable text.
- **Binary Image / Pixel Art Decoder:** Render binary matrices into visual text-based pixel art (perfect for challenges like the Arecibo message).
- **File to Binary Encoder:** Convert text files or ASCII art files into clean 8-bit binary streams.
- **CLI Friendly:** Avoids terminal buffer crashes and input blockages by reading seamlessly from file paths.
