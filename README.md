# Bin-Txt-Tools - This tools works in both macOS and Windows platforms, but works better on macOS

An open-source, lightweight CLI utility for macOS and Linux to encode and 
decode binary data and text.

## Installation

You can install `bin-txt-tools` globally with a single command:

```bash
pip3 install --user git+https://github.com/gustavodavidecoutinho/bin-txt-tools.git
